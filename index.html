常见问题
这个工具是干什么的？安全吗？

本工具是一个纯前端链接转换器，不代理、不缓存任何数据。你粘贴的链接仅在浏览器本地拼接，生成带加速前缀的新链接，由浏览器直接访问对应的公益镜像站。

本工具不接触你的文件内容，也不会记录任何链接历史。

链接无法下载 / 返回 404 怎么办？

常见原因有三个：

  • 镜像同步延迟：镜像站采用被动缓存，原仓库刚更新或删除文件时可能返回过期索引。
  • Release 资源直连 CDN：部分镜像不拦截 objects.githubusercontent.com 的下载请求，导致 Release 加速失效。
  • 镜像站临时故障：公益镜像的可用性随网络环境变化。

建议换成列表中其他节点重试，或先在 github.com 确认原始链接是否可访问。

可以用加速链接来 git clone 吗？

可以。部分镜像站支持 HTTPS 协议的 git clone：

git clone https://github.akams.cn/https://github.com/user/repo.git

也可以配置 git insteadOf 让所有 GitHub 操作自动走镜像：

git config --global url."https://github.akams.cn/https://github.com/".insteadOf "https://github.com/"

注意：克隆完成后建议将 remote 改回原始地址，否则后续 push 可能失败。
